# 开始游玩

BoardRaid 是 Minecraft Java 版 1.16.1 的BINGO竞赛模组。请按照安装指南获取最新的下载和启动器说明。
## 安装BoardRaid
1. 请按照[安装指南](https://boardraid.cn/download)获取最新的下载说明
2. BoardRaid目前要求：
   
   ·我的世界1.16.1版本
   
   ·Fabric Loader 0.18.4 或更新版本
   
   ·Java 8或更新版本
   
3.当有新版本更新时，BoardRaid会在游戏内提示你。

## 游玩第一局比赛
启动实例，在标题界面点 BoardRaid 入口。
 
游玩排位模式，和对手一齐选板。选牌阶段轮到你时，从给出的候选任务里挑一个放进卡板。倒计时走完才真正开始。
 
对局中按 J 打开卡板任务清单，按 B 回到选牌界面。这两个键都能在「选项 → 控制 → 杂项」里改。
